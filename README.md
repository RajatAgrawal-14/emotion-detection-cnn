 # Emotion Detection using CNN and ResNet50

This project detects human emotions from facial expressions using Deep Learning.

## Features

- CNN and ResNet50 model
- Real-time emotion detection
- OpenCV face detection
- Streamlit / Gradio deployment

## Dataset

FER2013 dataset (35,000 images)

## Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- Streamlit / Gradio

## How to run

pip install -r requirements.txt

streamlit run emotion_app.py

## Model

Custom CNN model trained on FER2013 dataset.
